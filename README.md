# 📊 Crime Against Women in India – Power BI Analysis

## 📌 Overview
**Crime Against Women in India: Trends and Analysis**  
Analysis based on NCRB data:
- Crime Data: 2001–2021  
- District Data: 2001–2014  
- Justice System Data: 2001–2010

This project focuses on analyzing crimes against women in India using multi-year datasets. The goal is to identify trends, highlight high-risk regions, and evaluate the effectiveness of the justice system through data visualization.

An interactive Power BI dashboard is created to transform raw data into meaningful insights.

---

## 🎯 Objectives
- Analyze crime trends over time (2001–2021)
- Identify most affected states and districts
- Understand distribution of different crime types
- Evaluate justice system performance (arrests, chargesheets, convictions)
- Highlight gaps between reported crimes and final outcomes

## 📈 Key Insights
- Crimes against women show an increasing trend over the years  
- Domestic violence is the most reported crime category  
- Certain states consistently report higher cases  
- Significant gap exists between arrests and convictions  
- High chargesheet rate does not always lead to high conviction rate
